# Calculadora Simples em Java 🧮

Criei esse projeto para colocar em prática o que venho aprendendo em Java e ir pegando o jeito com a sintaxe básica da linguagem. É uma calculadora que roda no terminal, organizada em menus para facilitar a navegação.

## 📌 O que já está funcionando

- **Operações básicas:** soma, subtração, multiplicação e divisão (com aviso se deu resto ou não).
- **Potências e raízes:** cálculo de potência ($a^b$), raiz quadrada, cúbica e raiz $n$-ésima.
- **Estatística:** média aritmética, média ponderada e mediana (usando `Arrays.sort` para ordenar os valores).

## 🛠️ O que foquei em praticar

- Entrada de dados pelo terminal usando a classe `Scanner`.
- Formatação de texto na saída com `System.out.format`.
- Lógica com estruturas de decisão e repetição (`switch-case`, `do-while` e `for`).
- Manipulação e ordenação de arrays.
- Métodos matemáticos da biblioteca `java.lang.Math` (`pow`, `sqrt`, `cbrt`).
- Separação de responsabilidades organizando o código em métodos.
